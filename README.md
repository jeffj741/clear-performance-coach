# CLEAR Performance Coach

A lightweight, responsive, browser-based practice tool for navigating difficult customer interactions with **CLEAR**:

1. **Connect** — acknowledge the concern.
2. **Listen** — clarify the real obstacle.
3. **Explain** — separate verified facts from unknowns.
4. **Act** — take an authorized action, refer, or escalate.
5. **Recap** — confirm ownership and the next step.

## MVP

- Five guided stages with sample phrases and editable practice responses.
- Five selectable practice situations: delayed service, conflicting information, authority exception, escalating frustration, or a general custom situation.
- Lightweight writing cues (not AI scoring or compliance determinations).
- Stage navigation and progress indicators.
- Printable-style recap text with one-click copy when the browser supports it.
- Responsive layout, labeled controls, status feedback, and reduced-motion consideration.
- No authentication, external dependencies, server calls, storage, telemetry, or data persistence.

**Privacy:** Do not enter real customer identifiers, protected information, account numbers, or confidential organizational details. All input is ephemeral and is lost on refresh. The recap is user-controlled.

**Safety:** This does not replace organizational policies, escalation paths, training, supervision, or emergency response. The user must verify facts and authority.

## Preview locally

Open `index.html` in a modern browser. No build tools are needed.

## Publish through GitHub Pages

Once the pull request is merged, go to **Settings → Pages** in the repo, choose **Deploy from a branch**, select **main** and **/(root)**, and save. The landing page is `index.html`.

## Follow-on enhancements

Potential next increments: branching scenario decisions, facilitator-authored scenario packs, optional local-only session exports, structured completion rubrics, and accessible microlearning modes. Do not introduce real customer data or automated compliance claims without a separate design and review.
